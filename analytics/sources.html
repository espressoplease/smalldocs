Visits by source

Each explicit ?src= value creates a source here when its first visit is recorded. Every source gets its own weekly chart and table.

Create a source while sharing: sdoc share report.md --short --source email-launch

The chart name is the lowercase value of src, with surrounding spaces removed. There are no aliases or inferred sources.

Targeted placements

Only short links carrying a valid pid appear here. A placement identifies where a link was published, not a person. These visits remain included once in the ordinary totals above.
