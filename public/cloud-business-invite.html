Install and configure SmallDocs Cloud for me.

1. Check whether the sdoc command is installed. If it is not, run: curl -fsSL https://smalldocs.org/install | sh
2. If sdoc is already installed, run: sdoc upgrade
3. Run: sdoc cloud login. Let me complete the browser authorization when it opens.
4. Run: sdoc setup --cloud --yes to enable Cloud-first sdocs and install the SmallDocs agent skill.
5. Run: sdoc cloud status --json and confirm this machine is connected.

For this workspace, use SmallDocs Cloud as the default. Use sdoc FILE.md for new and updated Markdown so the CLI creates or updates the Cloud document before it opens. Use +tag arguments for Cloud tags. Do not use local-only tags, the local library, or share links unless I explicitly ask.

If a command fails, stop and tell me what happened.

4How agents create and update sdocs

The SmallDocs skill teaches a supported coding agent how to create and open sdocs. The document remains Markdown, while SmallDocs adds navigation and richer blocks for code, diagrams, charts, cells, slides, math and video. Ask the agent to revise the same document when the work changes.

Explore every supported content block
5How Cloud storage and access work

Documents and revision history are stored in SmallDocs Cloud. Workspace membership, project grants and document permission groups control who can open and edit each document. SmallDocs manages the encryption keys required to provide authorised access. You can export the Markdown while the documents remain available.
